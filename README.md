# Showcase - Org Chart Creator - An Application for Team Hierarchies

## Overview

Org Chart Creator is an interactive organizational chart application that helps businesses visualize team structures, reporting relationships, and organizational hierarchies. Using Syncfusion Diagram components, users can create, customize, and share professional org charts through an intuitive drag-and-drop experience, improving communication, workforce planning, and organizational transparency.

---

## Key Features

- Create and manage organizational hierarchies
- Visualize reporting relationships
- Drag-and-drop chart editing
- Add, update, and remove employees or departments
- Role and designation management
- Interactive diagram navigation
- Brand customization and styling
- Export and share organizational charts
- Responsive web experience

## Syncfusion Components Used

### Diagram

Provides the primary visualization surface for building and managing organizational structures. It enables users to create hierarchy-based diagrams, connect employees and departments, and customize the appearance of organizational charts.

### Popup Components

Used for employee profile management, role updates, department assignment, confirmation dialogs, and chart configuration settings.

### DropDown List

Allows users to select departments, reporting managers, roles, designations, chart layouts, and organizational settings.
